## 1. 这是做什么的？

面向 NVIDIA 显卡（尤其是 CMP 挖矿卡）的小工具：

1. **强制功耗档位（模式）**
   - **省电模式**：降低功耗档位
   - **性能模式**：放开到高性能档位
   - **视频模式**：视频类负载用的档位（默认接近省电，可在配置中修改）

2. **自动切换**
   - 名单中的程序在运行 → 强制对应模式
   - 或按整卡 GPU / VPU 使用率阈值切换

3. **显卡切换（独显 / 核显）**  
   通过 Windows 图形性能偏好，为指定程序选择独显或核显（需重启该程序后生效）。

4. **状态监视**  
   当前/强制模式、使用率、频率、温度、功率，以及正在使用 NVIDIA GPU 的进程。

---

## 2. 运行环境

- Windows 10 / 11（x64）
- 已安装可用的 NVIDIA 驱动
- 本机至少有一块 NVIDIA GPU

说明：

- **目标 GPU** 在启动时由 NVAPI **动态枚举**。
- 魔改驱动下，任务管理器可能显示成其它型号（如 1660），本软件仍可能显示 CMP 30HX——通常是同一张卡。
- **CMP 30HX 等挖矿卡通常没有可用视频编解码引擎（VPU）**。「VPU 使用率模式切换阈值」对这类卡基本无效。

---

## 3. 安装与启动

1. 运行 `cmp-power-saver.exe`。
2. 同目录使用 / 生成 `config.yaml`。
3. 可勾选「随系统启动」。
4. 关闭窗口默认进入托盘。

---

## 4. 界面分区说明

### 状态

| 项目 | 含义 |
|------|------|
| 当前模式 | 驱动报告的当前档位（通俗名称） |
| 强制模式 | 本程序正在施加的目标模式 |
| GPU / VPU 使用率 | NVAPI 整卡域占用（与任务管理器算法不同） |
| 频率 / 温度 / 功率 | 传感器读数 |

占用率与温度对不上任务管理器时，多半是**统计口径不同**，不一定是读数错误。

### 目标 GPU

勾选后才对该卡施加限制；勾选状态会写入配置。

### 正在使用 NVIDIA GPU

按进程列出占用 NVIDIA GPU 的程序（与状态栏整卡占用是另一套数据）。

### 显卡切换

为列表中的程序设置独显 / 核显偏好。设置后请重启该程序。

### 运行即性能模式 / 运行即视频模式

名单中的程序在运行时强制进入对应模式。  
优先级大致为：**性能 > 视频 > 空闲（省电）**。

### GPU / VPU 使用率模式切换阈值

勾选后生效；滑条刻度为 5%。右侧 **?** 可查看完整说明。

- GPU：高于阈值 → 性能模式；低于 → 省电模式  
- VPU：高于阈值 → 视频模式；低于 → 省电模式  

---

## 5. 推荐用法（CMP 30HX）

1. 勾选你的 CMP 卡为「目标 GPU」。
2. 游戏加入「运行即性能模式」，或开启 GPU 使用率阈值（如 15%～30%）。
3. 双显卡笔记本可用「显卡切换」指定独显/核显。
4. 不必依赖 VPU 阈值。

## 7. 常见问题

**任务管理器占用和本软件差很多？**  
算法不同；魔改驱动下名称也可能不一致。

**强制模式不生效？**  
确认已勾选正确目标 GPU，并注意是否有其它工具同时改功耗档。

**独显/核显没变化？**  
需重启目标程序，且取决于系统是否尊重该偏好。
